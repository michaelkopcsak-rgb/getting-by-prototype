# Getting By — clickable prototype

A single-file HTML prototype of Getting By, an iPhone companion for people in counseling for depression and anxiety. Content is adapted from KMR Counseling micro-guides by Kristen Russell, LPC, used with permission.

- `index.html` — review page: iPhone frame plus review notes (laptop)
- `app.html` — full-screen iPhone version with Add to Home Screen support. **Generated** from `index.html` by `build-app.py`; don't edit it by hand.

Prototype only: nothing is saved or sent, and calls and texts are switched off.
